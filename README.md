# React Activity Portal

Team setup:
1. `npm install`
2. `npm run dev`
3. Each person only edits their own file in `src/pages/`.
4. Branch, commit, push, open a PR into `main`. Don't push straight to main.

Files:
- Activity 1 (Login) -> src/pages/Login.jsx
- Activity 2 (Grade Evaluation) -> src/pages/GradeEvaluation.jsx
- Activity 3 (Password Checker) -> src/pages/PasswordChecker.jsx
- Activity 4 (Electricity Bill) -> src/pages/ElectricityBill.jsx
- Activity 5 (Attendance Checker) -> src/pages/AttendanceChecker.jsx
